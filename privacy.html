Privacy Policy

Last updated: October 7, 2026

This tool is used only by its owner to upload the owner's own videos to the owner's own YouTube channel.

What the tool accesses

With the owner's permission, the tool uses the YouTube upload permission (youtube.upload) to publish videos to the owner's channel. It does not read, download or change any other data in the account.

What is collected and stored

The tool does not collect personal information from visitors or any other people. The only credentials it holds are the owner's own access credentials, stored as encrypted secrets in the owner's private GitHub repository. They are not shared with anyone.

Sharing

No data is sold, shared or disclosed to third parties. Videos are uploaded only to YouTube.

YouTube and Google

This tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The owner can revoke the tool's access at any time at Google security settings.
